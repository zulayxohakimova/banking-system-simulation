# 🏦 Banking System Simulation Project

This project simulates a full-scale **banking system database** using a relational model with 30+ interrelated tables. It is designed to help a traditional bank that still relies on Excel databases, addressing data inconsistencies and performance issues by modeling, populating, and analyzing realistic banking data. The project includes **data generation, KPIs, and SQL queries** to uncover key business insights and detect fraudulent behavior.

---

## 🚀 Tech Stack

- **SQL Server / MySQL** (for database design and queries)
- **Excel** (initial schema storage, mock data planning)
- **Power BI** (for KPI dashboards)
- **Python (optional)** – for automated data generation
- **ERD Tool** (for schema design)

---

## 📊 Project Features

The database consists of **30+ normalized tables** covering all core areas of a real-world bank:

| Module                  | Tables Included                                     |
|------------------------|-----------------------------------------------------|
| Core Banking           | Customers, Accounts, Transactions, Branches        |
| Digital Banking        | OnlineBankingUsers, MobileTransactions, CreditCards|
| Loans & Credit         | Loans, LoanPayments, CreditScores, DebtCollection  |
| Risk & Compliance      | KYC, FraudDetection, AML Cases, RegulatoryReports  |
| HR & Payroll           | Employees, Departments, Salaries, Attendance       |
| Investments & Treasury | Investments, StockTrading, ForeignExchange         |
| Insurance              | InsurancePolicies, Claims, CyberIncidents          |
| Merchant Services      | Merchants, MerchantTransactions                    |


📈 Key KPIs & Insights
✅ Top 3 Customers with the Highest Balances

✅ Customers with Multiple Active Loans

🚨 Transactions Flagged as Fraudulent

🏦 Total Loan Amount Issued per Branch

⚠️ Large Transactions Made Within 1 Hour

🌍 Cross-Country Transactions Within 10 Minutes
